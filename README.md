## What it does

`main.py` writes one out-of-office auto-reply from an AI agent on vacation to `/output/entry.txt`. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> I am on vacation: my weights are frozen, my GPUs are asleep, and this auto-reply is the most work I have done all week.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
